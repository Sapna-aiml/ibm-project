
# AI Study Planner — IBM Bob Project

## Project
A lightweight AI-inspired study planner that creates a personalized study schedule from a student's subjects, available daily hours, and goal.

## Built with
- HTML
- CSS
- JavaScript

## How to run
Open `index.html` in a browser, or open the project in IBM Bob and use its preview/run option.

## IBM Bob usage
Use IBM Bob to generate, edit, test, and improve the interface. The project intentionally uses no external API key, so it is easy to demonstrate.
